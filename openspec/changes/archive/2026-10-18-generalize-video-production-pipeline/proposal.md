# Proposal

## Why

当前项目把好礼乐品牌、工会福利卡券、像素街机风格等单一项目设定混入了视频生产 Skill 和工作流，导致框架难以复用，也容易将一次性产品背景误当作长期规则。需要把项目改造成工具无关的视频生产流水线：每个新项目先采集并确认自身背景，再用稳定流程生成、审查和迭代视频。

## What Changes

- 将项目级视频 Skill 与文档改为通用生产框架，移除固定品牌、产品、平台、视觉风格、受众和 CTA 默认值。
- 保留“产品/项目背景采集”作为每个新项目的必经步骤，提供空白背景档案模板，明确事实、来源、确认状态、限制与待确认项。
- 将固定核心规则与单条视频变量分开：核心负责流程、质量标准和安全边界；项目档案提供特定事实；任务卡只提供本条输入。
- 固化可复用的生产顺序、输出结构、素材连续性/版本台账、预演与质检门槛、局部返修和复盘方法。
- 将项目 HTML 说明改为通用流水线框架，不再包含好礼乐业务或像素风格作为默认。
- 补齐 OpenSpec proposal、design、specs、tasks，实施后将完成的 change 归档。

## Capabilities

### New Capabilities
- `video-production-pipeline`: 跨项目可复用的视频生产流程、背景采集、创作输出、资产连续性、质量门禁与复盘。

### Modified Capabilities
- 无。当前项目没有已有 OpenSpec 能力规格。

## Impact

- 将重构 `.agents/skills/haolile-video/` 为通用视频生产 Skill 与参考资料。
- 更新项目 HTML 说明页，并新增通用项目背景档案模板。
- 新增 `openspec/specs/video-production-pipeline/spec.md`；不引入视频生成器、付费服务或运行时依赖。
- 特化内容从活跃工作流中移除；本 change 仅保留其作为重构前状态的历史记录，不把它作为通用模板或默认事实。
