## 8. 使用规则
1. 用户或授权负责人明确确认的信息，才能升级为项目事实；保留来源、适用日期和范围。
2. 项目档案只适用于所属项目；不复制为其他项目默认值。
3. 单条临时设定不自动改写本档案。变更长期事实时更新版本并记录变更人/日期。
4. 发现过期、冲突或不清楚的陈述，先标注并缩小表述；不要自行裁决。
