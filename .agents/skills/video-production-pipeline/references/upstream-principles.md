# 上游工作流筛选原则

本文件记录可迁移的方法和筛选原则，不把任何第三方 Skill、模板、代码、素材或平台做成此流水线的强依赖。

## 可吸收的通用方法

- 先理解项目背景、受众、目标、平台、时长、素材、资源和限制，再选择制作工具。
- 将任务写成跨工具的 Brief；输出应可迁移到不同剪辑器、图像/视频模型或真人制作路线。
- 把抽象镜头描述改成可拍/可生成的动作、机位、构图、运动和限制。
- 按旁白/音乐结构处理声音节奏，重要动作与音效同步，并进行逐镜质量检查。
- 对重复角色/道具记录身份特征与可变状态，显式记录镜头交接。
- 参考作品只提炼节奏、叙事或镜头语法，不复制其脚本、独特画面、品牌、音乐或受保护表达。

## 外部来源使用纪律

- 研究特定外部仓库或 Skill 时，在使用时记录来源、访问日期、许可证及实际采纳内容；星数只作为当时的关注度快照，不能当作质量证明。
- 技术问题优先以一手文档/源代码/原始研究为依据。平台规则、模型能力、价格及推荐会变化，需要在实际使用前重新核验。
- 仓库代码许可证不自动覆盖音乐、图像、字体、商标、模型输出或素材中的第三方权利。
- 只摘录必要的工作方法，不复制大段文案或未经授权素材；只有确有需要且用户要求时才引入依赖。
- 若来源不清、授权不明或方法与项目规则冲突，跳过该方法并说明原因。
