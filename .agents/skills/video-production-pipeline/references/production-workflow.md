# 通用视频生产工作流

本文件定义跨项目复用的流水线。项目产品、品牌、平台、语气、视觉风格、时长和制作工具均从对应项目档案或单条任务获取，不在此设默认值。

## 一、生产分层

- **固定核心**：本工作流、事实与授权纪律、交付合同、连续性记录、质量门禁、返修方式。
- **项目背景档案**：该项目已确认的产品/服务、用户、场景、品牌表达、可公开主张、限制与素材权限。
- **单条视频 Brief**：本期目标、题目、核心结论、时长/规格、指定音乐、使用资产、资源边界与所需交付。

先读项目档案。没有档案就提供并填写 `project-background-template.md`；不要在档案缺失时擅自编写产品主张。

## 二、单条任务卡

```text
【项目/档案】名称、路径、版本；未建立则标记
【本条主目标】触达 / 关注 / 认知 / 转化 / 教学 / 其他（选一）
【目标观众】
【观众问题或需求】
【单一核心结论】观众看完只需记住什么：
【记忆锚点】一句话/图像/动作/声音（可选）
【平台与规格】明确填写；未知不默认
【目标时长】明确填写；未知不默认
【叙事/视觉/声音偏好】从项目档案继承，或声明单条覆盖
【可公开事实与证据】来源、核验日期、审批状态
【指定音乐/音频】文件/可访问链接；无则请求音乐方向
【引用资产】编号、版本、授权状态；无则标记待建立
【制作路线/资源限制】实拍/动画/生成/混合及工具、预算、工时
【唯一 CTA / 下一步】仅当任务需要
【本轮交付】选题/旁白/完整分镜/生成提示词/审片/其他
【本条额外限制】与项目长期设定不同的临时要求
```

## 三、固定创作顺序

1. **确认问题与边界**：核对项目档案和单条 Brief；标出缺失事实、冲突、时效和许可风险。
2. **收束创意**：确定一个观众、一个主要目标、一个问题、一个可证明/可解释的核心结论、一条叙事线和一个必要的下一步动作。开场提出的问题应在内容中兑现。
3. **规划声音**：若用户提供可访问音乐，先听并记录基调、速度感、能量变化、段落、音色和可用转折/重拍；区分听感与可测事实。若无曲目，只提出情绪、节奏密度、音色、结构方向及搜索词并标“待选”。不杜撰 BPM、曲名、授权或听感。
4. **写旁白和音画节奏**：旁白自然可录，按目标时长试读；据音乐安排断句、停顿、镜头长度、动作、转场、音效或留白。音乐不掩盖语言。节奏服务理解，不机械规定切镜频率。
5. **准备视觉资产**：需要跨镜连续时建立视觉设定表和参考图；锁定身份特征与允许变化，使用资产 ID/版本。若不需要连续角色/道具，避免为了流程而增加无用资产。
6. **写镜头与预演**：逐段输出画面、屏幕文字、声音、时间码和同步点。先用静帧、分镜或 animatic 验证叙事、时长、可读性与资产交接；通过后再制作完整素材。先校准代表镜头，再批量扩展。
7. **制作和质检**：核事实、文本、权利、声音层次、设备端可读性、镜头连续性、规格及最终交付。所有重大问题记录返修位置和原因。
8. **复盘**：记录实际工时、修改轮数、复用资产、结果数据的来源/时间窗/定义，以及下一轮待验证的一个假设。样本不足时只记录，不推断。

## 四、交付合同

按用户要求的交付范围裁剪，不为简短任务强塞整套材料。若要求完整视频制作方案，建议按以下顺序交付：

1. 简报理解与明确假设/待确认项。
2. 选题方案：目标、受众、问题、核心结论、记忆点、故事梗概、证据与风险。
3. 音乐分析（有实际音频时）或音乐方向与搜索词（无实际音频时）。
4. 完整旁白：口语化、可录制，注明试读后的大致时长和语气/停顿。
5. 时间码分镜表，每段至少含：
   - 画面轨：场景、景别、构图、具体动作/运镜/转场。
   - 屏幕文字轨：简洁、静音可读，不整段复制旁白。
   - 声音轨：旁白、音乐段落、同步音效/留白、混音优先级。
   - 资产引用：ID/版本、状态交接及允许变化（适用时）。
6. 连贯的故事化画面说明，能让制作人员想象从开头到结尾。
7. 素材清单、各镜头提示词/制作说明、唯一 CTA（任务需要时）。
8. 事实、权限和发布前 QA 清单。

## 五、连续性台账

当同一视觉元素跨镜头复用时，把下列列加入分镜表，不强制使用独立软件：

| 镜头 | 资产ID/版本 | 固定特征 | 本镜状态 | 构图/方向 | 场景/光色 | 允许变化 | 下一镜交接 | 授权/检查 |
|---|---|---|---|---|---|---|---|---|

只写本镜要发生的变化，不重塑已锁定身份。生成式模型不能保证精准遵循参考；如漂移明显，使用合成、局部编辑、剪辑替换或人工筛选。

## 六、质量门禁

- **G0 项目/选题**：档案适用；目标、观众、问题、核心结论、证据和交付范围明确。未知标注；事实边界有依据。
- **G1 脚本/声音**：故事因果清楚；旁白实际可读；音乐分析真实或建议明确标记；镜头动作服务内容；人声清晰。
- **G2 预演**：低成本检查镜头顺序、时长、屏幕文字、音画节奏与连续性。明显问题先退回修改，不进入昂贵制作。
- **G3 成片**：逐镜核事实/字幕、品牌或产品表述、权利许可、可读性、连续性、声音与输出规格。阻断项未解决不标记通过。
- **G4 复盘**：记录真实投入、修改、资产复用与可验证表现，给出一个下轮可测试改进。

## 七、受控修订模板

```text
请只按下列反馈修改当前版本。
必须改变：
保持不变：
允许替代：

先用不超过 3 点复述修改范围，再提交修改后的完整版本和改动清单。不要自行改变已确认的项目事实、核心结论、受众、风格、音乐方案或时长。若改动影响时长、声音、镜头节奏、资产状态或事实边界，联动检查受影响部分并指出仍待确认事项。
```

## 八、稳定性与效率

- 可复用的是结构、检查表、资产命名、审批状态和项目配置；不是将前一项目的创意/外观照搬到新项目。
- 一个完整样例、一次预演、一个代表镜头通过后，再扩大制作范围。
- 只返修失败镜头或受到影响的内容，保留已验收部分。
- 每轮尽量只改变一个实验变量，便于比较；质量门禁、事实核验和授权检查不能为省时而跳过。
- 若生成工具无法锁定参考图、种子或运动，明确限制并安排人工质检，不承诺绝对稳定。
