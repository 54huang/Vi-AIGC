# 项目档案治理规则

- 档案是经项目方批准的上下文摘要，不替代产品说明、合同、法律意见、官方规范或最新平台资料。
- 保留事实状态：已确认、待核验、过期、禁止公开。推断、愿景、创意和用户评价分别标示，不混为客观事实。
- 每项外部可验证主张保留来源和适用范围；涉及会变化的规则、价格、参数、政策或能力，在制作/发布前重新核验。
- 项目档案的生效范围要清楚：全项目、某产品线、某渠道、某栏目或单条活动。不可跨项目复制已确认事实。
- 对外身份、保证、比较级、收益、性能、客户案例、健康/安全/金融/法律等高风险陈述应要求明确来源与人工审核；证据不足则删除或降格为问题/假设。
- 视觉/声音偏好属于可配置创作设定，不等于产品事实。明确标注“长期项目设定”或“单条覆盖”。
- 保存素材授权及限制，包括渠道、期限、地区、剪辑/衍生使用、署名和撤回条件；未确认的素材不得视为可用。
- 记录档案维护责任人、版本与最近核验日期；新资料与旧资料冲突时，列出冲突请责任人裁决。
